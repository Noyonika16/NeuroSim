# NEURO-ELEGANS v13.3 — Chemotaxis experiment protocol

## Controller definitions
- **Assisted baseline:** direct food-bearing steering; network activity is telemetry only. Ablation should not materially affect action selection in this mode.
- **Neuron-only (default):** untrained lateral command/motor readout. No trained decoder, direct food-bearing steering, direct ASER-to-turn rule, or boundary-turn override is applied. A synthetic wall-proximity signal is encoded into ASH sensory input; only the neuron-state motor readout changes heading. Poor performance and boundary collisions are valid outcomes.
- **Trained neural hybrid:** a 105-feature Ridge turn readout trained offline to imitate assisted angular corrections, using neuron voltages after temporal concentration coding and a synthetic bilateral head-side concentration probe. It does not read food bearing at inference, but includes an ASER-associated turning adapter.

## Metrics
- **Food:** number of food targets collected.
- **Reorientations:** sustained or discrete heading changes generated by the selected controller; Neuron-only has no safety-guard turns.
- **Turn episodes:** continuous periods of measurable heading change; these are not the same as reorientations.
- **Pirouettes:** ASER-associated stochastic events only in the trained hybrid; none are directly injected in Neuron-only mode.
- **Body length:** body-segment count; each food adds one segment.
- **End reason:** boundary collision, self-collision, or 1,800-frame time limit.

## Controlled experiment
For each controller, run seeds `20261027`, `1`, `42`, `100`, `20261028`, and `123456`. Restore all neurons before intact controls. For ablation, apply the intervention before restarting, then record both the ablation set at trial start and at record time. Do not compare an intact run against an intervention introduced mid-run as if they were matched trials.

## Current headless calibration result
On the six-seed set, trained-hybrid Chemotaxis collected 1, 7, 16, 11, 9, and 3 food respectively (mean 7.83); one trial reached the 1,800-frame limit and five ended in boundary collision. In three Neuron-only trials, all scores were 0 and all ended in boundary collision. These negative outcomes are retained rather than masked by a safety override. These are finite-episode headless software results, not live-browser verification or biological validation.

## Interpretation
The sensory encoding, heading readout, body model, collision rules, and food-placement process are engineered task components. The Neuron-only mode has no heading safety override. The model is a connectome-inspired closed-loop simulation, not a complete biological worm. A successful score does not establish biological fidelity.
