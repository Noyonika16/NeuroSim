Controller modes: what is overridden?

Assisted baseline — Flappy: directly uses bird-to-gap vertical error to decide when to flap. Chemotaxis: directly steers toward the food bearing and uses distance-based speed. The connectome runs, but its readout does not determine those assisted actions.

Trained neural hybrid — Flappy: pipe-edge clearance, floor proximity, and edge-closing motion are encoded as synthetic sensory currents. A regularized linear readout over 99 sensory, command-interneuron, and motor-neuron voltages is trained offline to imitate the assisted reference's flap decisions. At runtime it reads neuron voltages only; it does not read bird height, gap center, or velocity. Connectome dynamics and synaptic weights remain frozen, but the output readout is trained, so this is not zero-shot emergent behavior.

Neuron-only (default): Flappy actions are triggered by the untrained DB−VB motor-neuron contrast; Chemotaxis curvature comes from untrained command/motor neuron-state asymmetry. There is no trained decoder, game-state action policy, direct ASER-to-turn rule, or boundary-turn override. The sensory transducers and virtual motor-to-game actuator mapping are still engineered assumptions. Expect poor performance; the real nematode circuit is not known to implement Flappy Bird control.

Chemotaxis sensory model: local concentration samples and a simplified temporal derivative are encoded into sensory-neuron currents. A synthetic wall-proximity signal is also injected into ASH sensory channels, but it does not directly change heading in Neuron-only mode. The trained hybrid additionally has an ASER-associated turning adapter. These are model abstractions, not a validated whole-worm locomotion model.

Ablation handling: if a selected neuron used as a trained Flappy readout feature is ablated, that feature is omitted (its training-mean value gives zero standardized contribution). Surviving neurons still reflect network-wide effects of the ablation. The record shows ablations at trial start and at record time. In Assisted baseline, the action policy bypasses the network, so behavior should remain largely unaffected by neuron ablation.

Metrics: in Neuron-only mode, reorientation counts reflect changes produced by the motor readout rather than safety-guard turns. Turn episodes count sustained smooth heading changes. These are operational game metrics, not biological constants.

Interpretation: this is a connectome-based computational model with trained/engineered input-output adapters, not a validated biological emulation. Scores alone do not establish biological intelligence.

Neuron-only mode is selected by default. Keep seed and ablation set fixed when comparing with the trained neural hybrid and assisted baseline.
